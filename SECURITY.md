# Security

## Secrets

Do not commit Amazon credentials, Redis URLs, tokens, Streamlit secrets, email app passwords or `VISITOR_HASH_SECRET`. Use the hosting provider's secret store. `.streamlit/secrets.toml`, `.env` and runtime databases are ignored by Git.

Rotate credentials immediately if they are exposed in commits, logs, screenshots, issues or chat messages.

## Runtime controls

- Product links rendered by the UI are restricted to HTTPS `amazon.it` hosts.
- Product images are restricted to known Amazon/CDN HTTPS hosts.
- Dynamic product text is HTML-escaped before rendering.
- External links use `noopener noreferrer`; affiliate links also use `sponsored`.
- Browser visitor identifiers expire after 90 days and can be regenerated by the user.
- Identifiers are HMAC-SHA256 pseudonymized when `VISITOR_HASH_SECRET` is configured; SHA-256 is the fallback.
- Invalid browser UUID values are rejected before use.
- Search rate limiting and API budget work with SQLite on a single instance; Redis is optional.
- If Redis is later enabled remotely, prefer `rediss://` TLS and centralize it through `redis_client.py`.
- Set `STRICT_REDIS=1` only on deployments that intentionally depend on Redis.
- HTML retrieval has timeouts, classification metrics and circuit breakers.
- Browser components use restrictive CSPs and avoid wildcard `postMessage` targets.

## GitHub and deployment

- Protect `main` so changes require a pull request and passing CI checks.
- Keep the Streamlit deploy key read-only unless write access is explicitly required.
- Review repository deploy keys periodically and remove only keys known to be obsolete.
- CI runs tests, Ruff, mypy, dependency auditing and secret scanning.
- CodeQL scans Python on pushes/PRs and on a weekly schedule.
- GitHub Actions are pinned to commit SHA and Dependabot continues to monitor updates.

## Optional multi-instance deployment

Redis is not required for the current single-instance design. If a future deployment uses multiple replicas, recommended environment values are:

```text
REDIS_URL=rediss://...
STRICT_REDIS=1
VISITOR_HASH_SECRET=<long-random-secret>
SCALA_SHARED_CACHE_REDIS=1
```

Without Redis the application uses SQLite/memory and is intended primarily for one application instance.

## Reporting

Security issues should be reported privately to the repository owner rather than by posting credentials or exploit details publicly.
